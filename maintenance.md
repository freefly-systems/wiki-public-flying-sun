# Maintenance

#### Tether cable&#x20;

Avoid stepping on tether cable.

If the tether cable is bent at a sharp angle, the wire can stick out the Kevlar sheath. Make sure to straighten any bent sections before use.

{% hint style="info" %}
If this wire comes out, you can try to coax it back into the sheath. If this is not possible, please [contact Freefly Support](https://freeflysystems.com/contact)
{% endhint %}

{% hint style="danger" %}
Do not fly or turn on HV with the internal tether wire exposed
{% endhint %}

#### Tether backup battery

Tether ground station has backup battery for keeping tension during a ground station power failure. please ensure the tether ground station is charged more than 50% before flight.

{% hint style="info" %}
The ground station uses power to reel in the cable, and it cannot be reeled in by hand
{% endhint %}

#### Light leaf&#x20;

User replaceable with (2) M3x6mm Socket Head Screws.
